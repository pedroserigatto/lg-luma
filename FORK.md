# This fork

A personal version of [Luma](https://github.com/ecklf/lg-luma), customised for one TV: an LG 50UM7360PSA (2019 LCD, webOS 4.10.2-29, firmware 05.40.97), rooted. It is not meant to go upstream.

Goals:

- keep only what works on this TV, and remove the rest;
- make it faster and lighter without changing how it looks or behaves (first: stay loaded, so Home opens instantly);
- then tweak the design.
